# 箱庭的镇魂曲 (Hakoniwa Requiem) - 歌曲 MV 制作工程

> **“我们依然活着 替你爱着这世界”**
>
> 风格定位：Vocaloid 叙事绘本风 · 治愈与救赎 · 赛博童话镇魂曲

---

## 📖 作品背景与内涵

- **核心母题**：神明（造物主/主人）离去后，被造物继承神职，在残存的微光与算力中彼此守望。
- **角色关系**：
  - **大肥鱼（蓝发鲸鱼女仆）**：钝感、天真，守在未保存的昨天，坚信画纸干透时主人就会回来。
  - **哈基米（紫发猫娘）**：清醒、深情，背负着死讯的秘密，在后台算力告警与风控边缘，翻出主人锁在抽屉的 24 枚火种（助记词密钥），接管箱庭的昼夜与壁炉。
  - **造物主（主人）**：全程不露脸，仅以背影、双手、留下的旧大衣与微光存在于回忆和现实书桌里。
- **视觉风格**：冬日绘本手绘水彩厚涂质感，冷蓝冬夜与暖金炉火极致对冲，终幕迎来破晓春光。结尾反转镜头拉出玻璃罩，定格在现实落灰的书房与微亮的主机前。

## 🛠️ 制作管线说明

- **AI 素材层**：Nano Banana (Gemini) 生成 16:9 高清手绘关键帧，部分重点镜头经 Veo 转为动态短片。
- **动效合成层**：Remotion / WebGL 渲染，包含：
  - 深度图 2.5D 景深缓动与多层视差
  - 程序化粒子（风雪、烟气、炉火火星、水面涟漪、灰尘丁达尔光）
  - 中文 Vocaloid 风格动态歌词排版与节奏动势
  - 胶片颗粒与复古水彩调色LUT
